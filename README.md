# sardorbek.codes

Personal site. One static page, no framework and no build step.

The custom domain is set on THIS repo on purpose: a domain on the user site
(`<user>.github.io`) is inherited by every project Pages site under the account
as a path, so `sardorbek.codes/<project>/` works for each of them. Setting it on
a project repo instead would consume the whole apex for that one project.

    sardorbek.codes/                              this page
    sardorbek.codes/olist-customer-intelligence/  project Pages, once enabled
